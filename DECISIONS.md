# Решения по проекту

Журнал всех согласованных решений. Новые решения добавляются сюда в том же коммите, что и изменения в коде.
Полное ТЗ: https://claude.ai/artifact/Bmc4DpPZG1uqqXDmEsUPdC

## Как работаем

- Сначала ТЗ, потом код; каждая версия проверяется на реальных тренировках.
- Когда нужны решения от пользователя — вопросы оформляются нумерованным списком, у каждого есть вариант по умолчанию.
- Все решения записываются в этот файл, в ТЗ и в `claude/status.md` проекта Claude.
- Код пушит Claude напрямую в `main` (fine-grained токен, доступ только к этому репозиторию). Локальная папка `Projects\training-app` синхронизируется через `git pull`; `publish.bat` — запасной вариант ручной публикации.
- Деплой: GitHub Actions → GitHub Pages, https://uladz13.github.io/training-app/

## Платформа

- PWA (TypeScript, Preact, Vite, vite-plugin-pwa, Dexie/IndexedDB), работает офлайн, тёмная тема, интерфейс на русском.
- Позже возможен переход на нативное Android-приложение (Kotlin + Compose + Room), когда набор функций устоится. Мост — JSON-бэкап с номером версии схемы.
- Данные только на телефоне; бэкап — JSON-файл (экспорт/импорт на экране «Ещё»), напоминание, если бэкапа не было 7 дней.
- Личные документы (`*.docx`) в публичный репозиторий не попадают.

## Инвентарь и веса

- Блины: 8 × 3 кг, 4 × 2,5 кг, 4 × 1,25 кг. Грифы гантелей и штанги пластиковые — вес 0 кг.
- Учитываем только симметричную сборку.
- Режимы: две гантели (вес одной), одна гантель, штанга (общий вес). Кнопки −/+ переключают только реально собираемые веса.

## Программа и данные

- Шаблоны дней — по текущему списку упражнений пользователя (21.10.2026); диапазоны повторений и отдых — из исходной программы.
- Французское разгибание — с двумя гантелями; ягодичный мост (Вт, Сб) — со штангой.
- Растяжки (Чт, Вс) — отдельные упражнения с описанием техники.
- Стартовая история: текущие рабочие веса записаны как тренировки 12–21.10.2026.

## Тренировка

- Каждый подход записывается отдельно; предзаполнение — с прошлого такого же дня недели (иначе из шаблона).
- Упражнения в тренировке можно добавлять (из каталога или новое), удалять, редактировать, переставлять.
- Отметку «выполнено» у подхода и упражнения можно снять. Все подходы отмечены → упражнение выполнено.
- Разминка и заминка — по одной галочке; у заминки описание, что растянуть.
- Таймер отдыха только информирует: после подхода — 20 с, после последнего подхода — отдых упражнения из программы. «Стоп» — сброс. Вибрация при включённом экране; во время тренировки экран не гаснет.
- Отметки обновляются на экране мгновенно, запись в базу — фоном.
