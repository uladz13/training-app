# Решения по проекту

Журнал всех согласованных решений. Новые решения добавляются сюда в том же коммите, что и изменения в коде.
Полное ТЗ: https://claude.ai/artifact/Bmc4DpPZG1uqqXDmEsUPdC

## Как работаем

- Сначала ТЗ, потом код; каждая версия проверяется на реальных тренировках.
- Когда нужны решения от пользователя — вопросы оформляются нумерованным списком, у каждого есть вариант по умолчанию.
- Все решения записываются в этот файл, в ТЗ и в `claude/status.md` проекта Claude.
- Claude кладёт изменения в локальную папку `Projects\training-app` и пишет команды git для cmd; пользователь публикует их сам (так полезнее для него). `publish.bat` убран. Изменения не считаются опубликованными, пока пользователь не подтвердил пуш или Claude не проверил его через `git fetch` (сверка дерева файлов с GitHub). Пуш напрямую из облака Claude заблокирован: репозиторий не подключён к сессии.
- Деплой: GitHub Actions → GitHub Pages, https://uladz13.github.io/training-app/

## Платформа

- PWA (TypeScript, Preact, Vite, vite-plugin-pwa, Dexie/IndexedDB), работает офлайн, тёмная тема, интерфейс на русском.
- Позже возможен переход на нативное Android-приложение (Kotlin + Compose + Room), когда набор функций устоится. Мост — JSON-бэкап с номером версии схемы.
- Данные только на телефоне; бэкап — JSON-файл (экспорт/импорт на экране «Ещё»), напоминание, если бэкапа не было 7 дней.
- Личные документы (`*.docx`) в публичный репозиторий не попадают.

## Инвентарь и веса

- Блины: 8 × 3 кг, 4 × 2,5 кг, 4 × 1,25 кг. Грифы гантелей и штанги пластиковые — вес 0 кг.
- Учитываем только симметричную сборку.
- Режимы: две гантели (вес одной), одна гантель, штанга (общий вес). Кнопки −/+ переключают только реально собираемые веса.

## Программа и данные

- Шаблоны дней — по текущему списку упражнений пользователя (21.10.2026); диапазоны повторений и отдых — из исходной программы.
- Французское разгибание — с двумя гантелями; ягодичный мост (Вт, Сб) — со штангой.
- Растяжки (Чт, Вс) — отдельные упражнения с описанием техники.
- Стартовая история: текущие рабочие веса записаны как тренировки 12–21.10.2026.

## Тренировка

- Каждый подход записывается отдельно. Новая тренировка (с v0.4): список упражнений, цели и отдых — из программы дня; вес, повторы и число подходов — с прошлого раза этого упражнения (сначала прошлая тренировка того же дня недели, иначе любая более ранняя); если упражнение ещё не выполнялось — стартовый вес из программы. Упражнение, добавленное в одну тренировку, само в следующие не попадает — для этого его добавляют в программу.
- Упражнения в тренировке можно добавлять (из каталога или новое), удалять, редактировать, переставлять.
- Отметку «выполнено» у подхода и упражнения можно снять. Все подходы отмечены → упражнение выполнено.
- Разминка и заминка — по одной галочке; у заминки описание, что растянуть.
- Таймер отдыха только информирует: после подхода — 20 с, после последнего подхода — отдых упражнения из программы. «Стоп» — сброс. Вибрация при включённом экране; во время тренировки экран не гаснет.
- Отметки обновляются на экране мгновенно, запись в базу — фоном.

## Прогрессия (v0.2)

- Источник подсказки — это же упражнение в прошлой тренировке того же дня недели.
- Не все подходы выполнены → повторить ту же нагрузку.
- Не везде верх диапазона → тот же вес, цель +1 повторение.
- Везде верх диапазона → следующий собираемый вес, повторения с низа диапазона; кнопка «Применить» или «Оставить как есть».
- Шаг веса больше 20% → предупреждение и альтернативы (опускание 2–3 с, пауза, +1 подход), применить вес всё равно можно.
- Вес уже максимальный (пара 19,5 кг) → только альтернативы.
- Без веса / на время → подсказка об усложнении, когда достигнут верх диапазона.
- Подсказка показывается до первого отмеченного подхода; решение («принято»/«скрыто») хранится в тренировке.
- В карточке упражнения — раскладка блинов на сторону; на экране «Ещё» — калькулятор весов (пара гантелей, одна гантель, штанга).

## Длительность и объём (v0.2)

- Таймер длительности стартует при создании тренировки; пауза/продолжение кнопкой; при «Завершить» останавливается, при «Вернуть в работу» продолжается с накопленного значения.
- Таймер считает реальное время, пока тренировка не завершена и не на паузе — в том числе при закрытом приложении; незавершённая тренировка продолжает отсчёт при повторном открытии.
- Длительность можно отредактировать вручную (часы и минуты) — нажатием на время.
- Тренировкам стартовой истории (12–21.10.2026) — 50 минут.
- Объём (тоннаж) = сумма «вес × повторения» по выполненным подходам, как в Strong/Hevy/Jefit. Пара гантелей — вес × 2; упражнение на сторону — повторы обеих сторон; упражнения без веса и на время не входят.
- Объём и длительность показываются в шапке тренировки, на экране «Сегодня» и в «Истории».

## Замеры тела (v0.3)

- Утренний вес (шаг 0,1 кг) и талия (шаг 1 см) вводятся в карточке «Утренний замер» на экране «Сегодня»; поля заполнены последними значениями.
- Талия записывается по желанию (кнопка «+ Талия»); напоминание раз в неделю — если последней записи талии 7+ дней.
- Вкладка «Тело» в нижней панели: плитки «среднее веса за 7 дней» с изменением за неделю и «талия» с изменением с первой записи; графики веса и талии — точки замеров, соединённые линией (линию среднего на графике не рисуем); таблица всех записей с правкой, удалением и добавлением за любую дату.
- Период графиков выбирается двумя датами (календарь); по умолчанию — последние 14 дней (сегодня − 14 … сегодня), ссылка «Последние 14 дней» возвращает его. Таблица записей показывает все записи.
- Для ввода старых данных (вес и талия с мая) — кнопка «Сохранить и след. день» в окне нового замера.
- Среднее за 7 дней — по календарным дням, включая текущий, только по дням с записью веса.
- Стартовые замеры 12–21.10.2026 (переданы пользователем) записываются один раз при обновлении или первой установке.
- Тест отжиманий и напоминание о нём пока не делаем — пользователь их сейчас не замеряет.

## Прогресс по упражнениям и программа (v0.4)

- Вкладка «Тело» переименована в «Прогресс» с переключателем «Тело | Упражнения».
- Метрики — по образцу Hevy/Strong, без расчётного 1ПМ (наши диапазоны 8–20 повторов, формулы 1ПМ неточны выше 12; вес упирается в набор блинов):
  - с весом: «Макс. вес» (по умолчанию, в подписи — повторы этого подхода), «Объём», «Повторы» за тренировку;
  - без веса: «Лучший подход», «Повторы за тренировку»;
  - на время: «Лучшее время».
- Экран упражнения: метрика, период (по умолчанию последние 3 месяца), график, рекорды за всё время, список тренировок со ссылкой на каждую. Открывается из списка в «Прогресс → Упражнения» и кнопкой «График» в карточке упражнения на тренировке.
- «Объём по неделям» (пн–вс) — столбики вверху раздела «Упражнения», период по умолчанию — последние 8 недель.
- Редактор программы («Ещё → Программа по дням»): название дня, разминка, заминка, добавление/удаление/перестановка упражнений, подходы, диапазон, отдых, стартовый вес. Сохраняется сразу.
- Каталог («Ещё → Каталог упражнений»): переименование и описание техники для всех; удаление — только своих упражнений без записей (заодно убираются из программы).

## История

## Не делаем

- Самочувствие, велосипед (трекается в Strava), кнопку «колено», «лёгкий день», аккаунты, синхронизацию, питание, уведомления.
